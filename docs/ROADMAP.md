# AMC Stock → ระบบหลักบริษัท (Roadmap)

ต่อยอดจากระบบวัสดุปัจจุบัน → เพิ่ม **CRM (ลูกค้า)** + **BOQ/ใบเสนอราคา** + **เทียบกำไรต่องาน**

## วงจรการทำงานเป้าหมาย
```
ลูกค้า (CRM)
   └─> ใบเสนอราคา/BOQ ──(ลูกค้าตกลง)──> งาน ──> เบิกวัสดุจริง ──> ต้นทุนจริง
          │  รายการ = วัสดุ(ราคาขาย) + ค่าแรง/บริการ                        │
          │  − ส่วนลด + VAT 7% = ยอดเสนอ                                    │
          └──────────────  กำไร = ยอดเสนอ − ต้นทุนจริง  ◄──────────────────┘
```
**จุดขาย:** รู้กำไรจริงต่อใบเสนอราคา/งาน เพราะต่อกับต้นทุนวัสดุที่เบิกจริง (ค่าเฉลี่ยถ่วงน้ำหนัก)

## สิ่งที่มีอยู่แล้ว (ฐานราก)
ล็อกอิน+สิทธิ์ · วัสดุ (ต้นทุน/ราคาขาย/รูป/ขั้นต่ำ) · เบิก-คืน-ซื้อ-เสีย (ผูกงาน) · งาน+ต้นทุนจริง · ใบสั่งซื้อ · แดชบอร์ด · จัดการทีม/ผู้ใช้/หมวด · Supabase+Vercel+GitHub

## โมดูลที่จะเพิ่ม + ตารางข้อมูล

### 1) CRM — ลูกค้า
- `customers`: ชื่อ · เบอร์ · อีเมล · ที่อยู่ · เลขผู้เสียภาษี · ผู้ติดต่อ · หมายเหตุ
- (ออปชัน) `customer_sites`: ไซต์งานหลายแห่งต่อลูกค้า
- หน้า: รายชื่อลูกค้า · เพิ่ม/แก้ไข · หน้ารายละเอียด (เห็นใบเสนอราคา + งานของลูกค้า)

### 2) BOQ / ใบเสนอราคา
- `quotations`: เลขที่ใบ · ลูกค้า · ชื่องาน/ไซต์ · สถานะ (ร่าง/ส่งแล้ว/ตกลง/ปฏิเสธ/หมดอายุ) · วันที่ · ใช้ได้ถึง · ส่วนลด(บาท/%) · VAT 7% · หมายเหตุ
- `quotation_items`: ประเภท (วัสดุ/ค่าแรง) · วัสดุ(อ้างคลัง) หรือชื่อรายการอิสระ · หน่วย · จำนวน · ราคา/หน่วย · รวม
  - รายการวัสดุ: ดึง "ราคาขาย" จากคลังมาตั้งต้น (แก้ได้)
  - รายการค่าแรง/บริการ: พิมพ์ชื่อเอง (เช่น ค่าติดตั้ง, ค่าเดินท่อ)
- คำนวณ: ยอดรวม → − ส่วนลด → + VAT = ยอดสุทธิ
- พิมพ์เป็นใบเสนอราคา (หัวบริษัท+โลโก้) · คัดลอก/ส่งลูกค้า

### 3) เชื่อมใบเสนอราคา ↔ งาน (กำไร)
- `jobs` เพิ่มช่อง: `customer_id`, `quote_no` (ผูกใบเสนอราคา)
- ใบที่ "ตกลง" → สร้าง/ผูกงาน
- หน้าเทียบกำไร: **ยอดเสนอ** vs **ต้นทุนวัสดุจริง** = กำไรขั้นต้น
  - (เฟสหลัง) เก็บต้นทุนค่าแรงจริง เพื่อกำไรสุทธิเต็มรูปแบบ

## แผนเป็นเฟส (ส่งมอบทีละชิ้นที่ใช้ได้จริง)
- **เฟส 1 — CRM:** ลูกค้า เพิ่ม/แก้/ดู (รากฐานของใบเสนอราคา)
- **เฟส 2 — ใบเสนอราคา/BOQ:** สร้างใบ (วัสดุ+ค่าแรง · ส่วนลด · VAT) · สถานะ · พิมพ์ · คัดลอก
- **เฟส 3 — เชื่อมงาน+กำไร:** ตกลง→สร้างงาน · เทียบยอดเสนอ vs ต้นทุนจริง
- **เฟสต่อไป (อนาคต):** ต้นทุนค่าแรงจริง · ใบแจ้งหนี้/ใบเสร็จ · ติดตามการชำระเงิน · แดชบอร์ดยอดขาย/กำไร

## ข้อพิจารณา
- ข้อมูลจริงเริ่มมีแล้ว → ทุก migration ใช้แบบปลอดภัย (`add column if not exists`) ไม่กระทบของเดิม
- อาจเพิ่มบทบาท "ฝ่ายขาย (sales)" แยกจากธุรการในอนาคต
- ภาษีหัก ณ ที่จ่าย / ใบกำกับภาษี — เพิ่มทีหลังได้
- ควรเปิด backup อัตโนมัติของ Supabase เมื่อขึ้น Pro
- ต้นทุน: ยังอยู่ในระดับ Supabase ฟรี/Pro (~$25/เดือน) · งานหลักคือเวลาพัฒนา ทำทีละเฟส
