## ตอนนี้คลิกการ์ดตัวเลขเข้าไปดูรายละเอียดได้แล้ว

การ์ดทั้ง 4 ใบในแดชบอร์ด (**ยอดเบิก / วัสดุที่ใช้จริง / ยอดซื้อ / วัสดุเสียหาย**) คลิกได้ — มี hover ยกตัวขึ้นและปุ่ม **"ดูรายละเอียด ›"** กำกับ

คลิกแล้วจะมี **แผงรายละเอียดเลื่อนออกมาด้านขวา** แสดง 3 ส่วน:
1. **แยกตามทีม** — กราฟแท่ง ARM/KENG/BOM/PAT พร้อมมูลค่าและ %
2. **แยกตามวัสดุ** — รายการวัสดุทุกชนิด เรียงมาก→น้อย พร้อมจำนวนหน่วย
3. **รายการธุรกรรม** — ลิสต์รายตัว (ทีม · เลขที่งาน · วันที่) — ของเสียมี**ป้ายสาเหตุ** / ใช้จริงมีรายการ**คืน**สีเขียวกำกับ

ยอดรวมในแผงจะ**ผูกกับช่วงเวลาที่เลือก** (วัน/เดือน/ปี/ตลอดอายุ) ปิดได้ด้วยปุ่ม X, กดพื้นหลัง หรือปุ่ม Esc

> หมายเหตุเล็กน้อย: ภาพตัวอย่างที่ผมจับได้ไม่โชว์แผงนี้เพราะเครื่องมือ snapshot จับ overlay แบบ fixed ไม่ติด แต่ในเบราว์เซอร์จริงแสดงปกติครบถ้วน (ผมตรวจ DOM ยืนยันยอดและรายการตรงกับ KPI ทุกตัวแล้ว) — ลองคลิกการ์ดดูได้เลยครับ

อยากให้ผมทำให้คลิกเจาะลึกได้อีกชั้นไหม เช่น คลิกที่**ทีม**เพื่อดูเฉพาะงานของทีมนั้น หรือคลิก**วัสดุ**เพื่อดูประวัติการเคลื่อนไหวของรายการนั้น?

## การ์ด "ต้องสั่งซื้อเพิ่ม" บนแดชบอร์ด (เดิมคือ "ต่ำกว่าขั้นต่ำ")

- บรรทัดรอง: `เหลือ X · ขั้นต่ำ Y` ให้เห็นทั้งสองค่า

## สิ่งที่เพิ่ม

**🔍 ช่องค้นหา**
ค้นได้จาก **ชื่อไทย / ชื่ออังกฤษ / รหัส / หมวด** กรองสดทันที (เช่นพิมพ์ "สายไฟ" เหลือ 3 รายการ) มีปุ่มล้างคำค้น

**➕ เพิ่มวัสดุใหม่**
ปุ่ม "เพิ่มวัสดุ" เปิดฟอร์ม — รหัส, หมวด, ชื่อไทย/อังกฤษ, หน่วย, ต้นทุน, จำนวนขั้นต่ำ, คงเหลือเริ่มต้น — เพิ่มแล้วโผล่ในคลังทันที (ติดป้าย "ใหม่")

**📜 ประวัติการเคลื่อนไหวแบบละเอียด**
คลิกการ์ดวัสดุใดก็ได้ → เปิดแผงด้านขวาแสดง:
- **คงเหลือปัจจุบัน** + มูลค่า + ขั้นต่ำ + ต้นทุน/หน่วย
- **สรุปการเคลื่อนไหวตลอดอายุ** 4 ประเภท (ซื้อเข้า / เบิกออก / รับคืน / ตัดเสีย) — แตะการ์ดเพื่อกรองได้
- **ไทม์ไลน์รายการเคลื่อนไหว** ทุกครั้ง พร้อมไอคอน·สี·ทีม·เลขที่งาน·สาเหตุ และจำนวนเข้า/ออก (+/−) เรียงล่าสุดก่อน

> หมายเหตุเดิม: ภาพที่ผมจับเองไม่โชว์แผงป็อปอัป (เครื่องมือจับ overlay แบบ fixed ไม่ติด) แต่ในเบราว์เซอร์ของคุณแสดงปกติเหมือนแผง drill-down ก่อนหน้า — ลองคลิกการ์ดในหน้าคลังวัสดุดูได้เลยครับ

อยากให้ค้นหา/ดูการเคลื่อนไหวนี้ใช้ได้จากหน้าอื่นด้วยไหม (เช่นคลิกชื่อวัสดุในแดชบอร์ดหรือหน้าจัดซื้อแล้วเด้งมาดูประวัติเดียวกัน) หรือปรับเพิ่มเติมส่วนไหนบอกได้ครับ
