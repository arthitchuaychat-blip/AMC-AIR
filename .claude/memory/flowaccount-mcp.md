เจ้าของเชื่อม FlowAccount AI Connector (MCP) เข้ากับ Claude แล้ว (2026-07-25). ต้องเปิดสวิตช์ที่ MyCompany → ตั้งค่าผู้ใช้งาน → ข้อมูลส่วนตัว → AI Connector (รายผู้ใช้ · เปิดแล้วต้อง reconnect MCP ให้ token ใหม่เห็น).

**ขอบเขต: อ่านอย่างเดียว** — เครื่องมือเป็น list/get/report/validate เท่านั้น สร้าง/แก้/ลบเอกสารไม่ได้ · ไม่มีเครื่องมือ payroll · เจ้าของเคยถามให้บันทึกซื้อ/ค่าใช้จ่าย/เงินเดือนแทน → ตอบว่าทำไม่ได้ (read-only) และไม่ควรให้ AI โพสต์เข้าระบบบัญชีจริงอัตโนมัติ (มีนัยภาษี ย้อนยาก) — ถ้าจะลดงานกรอกซ้ำ ทางที่ถูกคือ "ERP อนุมัติ → ส่งเข้า FA โดยมีคนกดยืนยัน + กันซ้ำ".

**บริษัทที่ MCP เกาะ = "เอเอ็มซี มัลติ-บิซ จำกัด" (support_code N498831)** — เจ้าของมี 28 บริษัทใน FA. ⚠️ ต้องยืนยันว่า ERP ยิงใบกำกับ (flowaccount-doc.js ใช้ FLOWACCOUNT_CLIENT_ID/SECRET ใน Vercel) เข้าบริษัทเดียวกันนี้ไหม — วิธีเช็ก: เอา flowaccount_no ของใบเสร็จ ERP ไปหาใน MCP · เลขที่ใน N498831 รูปแบบ `INV2026######`. ดูจากรายชื่อลูกค้า (โรงเรียนนานาชาติ/รพ./บริษัทตกแต่ง) น่าจะใช่บริษัทที่ใช้บิลงานแอร์.

**งานค้าง: กระทบยอดขาย ERP ↔ FA** (ตกลงขอบเขต: ใบกำกับ/ใบเสร็จ VAT · ช่วงตั้งแต่ ERP เริ่มใช้ ปลาย มิ.ย. 2026). ฝั่ง FA ดึงแล้ว = **59 ใบกำกับ ยอด ฿4,495,881 VAT ฿294,123** (20 มิ.ย.–25 ก.ค. · ไม่รวม void 2 ใบ INV2026070015/016 · ตัด INV2026030106 ที่ลงวันที่ มี.ค. ออก). เหลือรันฝั่ง ERP: `select ... from receipts where issue_date between '2026-06-20' and '2026-07-25' and coalesce(vat_amt,0)>0 and status<>'cancelled'` — นับ/รวม total, แยกที่มี/ไม่มี flowaccount_no, และเอา flowaccount_no ไปจับคู่กับ 59 serial ข้างบน. คำตอบที่ต้องการ: ยอดตรงไหม · ใบที่ ERP มีแต่ยังไม่ส่ง FA (ต้องตามส่ง) · ใบที่ FA มีแต่ ERP ไม่มี (ออกตรงใน FA). ดู [[stale-cache-deploys]] เรื่อง ERP push receipts→FA.
