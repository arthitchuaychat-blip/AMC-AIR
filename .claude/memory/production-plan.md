- **Costing = Weighted Moving Average** (user chose over FIFO). Purchase form has a per-line price input (defaults to material's current avg cost). On purchase submit, each material's `materials.cost` is recomputed: newAvg = (onHandQty*cost + pQty*pPrice)/(onHandQty+pQty) via `updateMaterialCost`. All valuation (stock value, withdraw/damage cost) uses this avg; return/damage-from-job still uses the issued cost. No DB migration needed (uses materials write RLS = admin; purchases are admin-only anyway).
