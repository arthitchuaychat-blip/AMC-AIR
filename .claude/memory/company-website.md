Public **company website + storefront** at `company-website/index.html` — single self-contained HTML file (Thai), now **AMC AIR branded** (AC business, primary `#0ea5e9`). Double-click to open, or serve via the static server (port 8123) at `/company-website/index.html`.

Rebuilt 2026-06-24 (v181, migration 071) from the old placeholder into a real storefront wired to the back office via the **same Supabase** as [[vatsadu-os-app]]:
- Sections: hero, services (ติดตั้ง/ล้าง/ซ่อม), **live product grid**, portfolio (static), reviews (static), contact + floating **cart drawer**.
- Config block `window.AMC_CONFIG` at top of the file — user must paste `SUPABASE_URL` + `SUPABASE_ANON` (same public values as app/.env). Without them it shows sample products and disables ordering.
- Reads products from the `web_products` **view** (safe columns only — no cost); submits to `web_orders` table via the **anon key** (RLS: anon can only INSERT). A DB trigger rings the back-office notification bell on each order.
- Back office: new "คำสั่งซื้อจากเว็บ" module (`weborders` / WebOrders.jsx) is the order inbox; Catalog has a "แสดงบนเว็บ" toggle (`materials.web_published`). Migration 071 also recreated the `material_stock` view for the new column.

**Two-column layout (2026-06-28, v209):** homepage is a CSS-grid `.page` = left rail (`.side-filter` sticky: รุ่นแอร์/ประเภท/บริการ selects + "ดูสินค้า/บริการ" button → `applyHeaderFilter` routes to products; `.side-rail`: latest web_press image as "ภาพข่าว" + web_ads banners) and `.maincol` (banner slideshow → clients → portfolio → articles → services/reviews/press/faq/contact). Products/services are NOT on the homepage — they live on a **hash-routed page** `#pageProducts` (`route()` on hashchange toggles `#pageHome` vs `#pageProducts`; footer always shown) so product **detail pages can be added later**. Mobile: grid collapses, filter on top, ads pushed below content via `order`. New content type **ภาพโฆษณา (แถบข้าง)** = migration 080 `web_ads`, managed via the generic WebManage tab (kind `ads`).

**Hero banner slideshow (migration 078 `web_banners`):** full-width cover slideshow auto-advancing every 2s (prev/next + dots), replacing the split hero when banners exist. Source priority: Supabase `web_banners` (active, by sort) → `C.BANNERS` config array fallback → else the Midnight Glass hero.

**"จัดการเว็บไซต์" module (v207, migration 079) — the graphics team's home:** new nav module `website` (group ลูกค้า & ขาย; permission `website`=E for admin/exec/sales). `WebManage.jsx` = 5 tabs, each a generic `WebItemManager` (upload image + text fields + reorder ◀▶ / show-hide / delete): **ปก/สไลด์โชว์ (web_banners) · อัลบั้มผลงาน (web_portfolio) · โลโก้ลูกค้า (web_clients) · บทความ (web_articles) · ข่าวในสื่อ (web_press)**. Migration 079 adds web_portfolio/web_articles/web_press (public-read-active / office-write, like web_clients). `WebOrders.jsx` was trimmed back to just the order inbox (its old banner/client tabs moved here). The website's loadPortfolio/loadArticles/loadPress/loadClients/loadBanners each pull from Supabase when connected, else fall back to config (PORTFOLIO/BANNERS) or the static HTML.
