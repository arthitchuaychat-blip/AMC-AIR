เมนู **"แชตลูกค้า"** (เดิม "แชต LINE", เปลี่ยนชื่อ v548) id `chat` = [Chat.jsx](app/src/components/Chat.jsx) · 3 แท็บ: LINE / Facebook / 🏭 ซัพฯ (ซัพ = ตาราง line_contacts kind=supplier). แบ็กเอนด์: `app/api/line-webhook.js` (รับ+บอท AI), `line-send.js` (ส่ง push), `fb-webhook.js`/`fb-send.js`. ตาราง `line_contacts`/`line_messages`/`line_contact_customers`, `fb_contacts`/`fb_messages`, `quick_replies`. **ส่งทุกข้อความผ่าน LINE push API** (กินโควตา ไม่มีตัวนับ). ดู [[ai-line-bot]] [[line-oa-chat]] [[notifications]].

**พักก่อนส่ง (v549-550, 2026-08-02).** เดิมเลือกรูป/ไฟล์/การ์ดสินค้า/เอกสาร = **ส่งทันที**. เปลี่ยนเป็น **"พักไว้ในช่องแชต ตรวจแล้วค่อยกดส่ง"**: state `pending` [{type:'image'|'file',url,name}] + `uploading` · `onImage`/`onFile` push เข้า pending (multiple), `send()` ส่ง text+qrPendImgs+pending ตามลำดับ · การ์ดสินค้า `sendChatCart` → รูปสินค้า+ตารางราคาเข้า pending, โบรชัวร์เข้า text (ปุ่ม "📎 แนบเข้าแชต") · เอกสาร: `captureDocToStage()` ใน [lib/sendDoc.js](app/src/lib/sendDoc.js) คืน {attachments,text} (image→pending รูปทุกหน้า, pdf→ลิงก์เข้า text) แทน sendDocFromNode · **emoji picker** (ปุ่ม 😀, ใช้ Emoji รุ่นเก่า) แยกจากสติกเกอร์.

**แจ้งเตือนผู้รับผิดชอบ + เปิด FB (v550).** เดิม `notifyCustomerChat` (line-webhook) แจ้ง sales/admin/exec ตาม role เท่านั้น — เพิ่ม **assigned_to ของแชตนั้น** เข้า recipient เสมอ (คนดูแลลูกค้าได้เตือนแม้ role ปิด). **FB inbound เดิมไม่แจ้งเตือนเลย** → เพิ่ม `notifyFbChat` (fb-webhook, mirror LINE: role+assigned_to, bell+web push, ref_type "fb"). fb_contacts มี assigned_to (mig 043). (openNotif ยัง focus FB ไม่ได้ — เข้าเมนูแชตเฉย ๆ, รอเฟส FB parity).

**เฟส 4-6 (v551, 2026-08-02, mig 189).** **เฟส 6 โน้ต+แท็ก:** mig 189 add `note text`,`tags text[]` ทั้ง line_contacts+fb_contacts (+`fb_messages.quoted_message_id`) · api `setLineNote/setLineTags/setFbNote/setFbTags` · Chat แผงขวาเพิ่มช่องโน้ต (textarea uncontrolled key=sel, save onBlur) + แท็ก chips (`.chat-tag`) — ผ่าน `changeNote/changeTags` (channel-aware). **เฟส 5 ปุ่มลูกค้ากด (LINE native quick-reply):** state `qrButtons[{label,text}]` + ปุ่มเครื่องมือ "🔘 ปุ่มลูกค้า" + ตัวแก้ไข (≤13, label≤20) · send() ส่ง `quickReplies` ผ่าน sendLineMessage opts → line-send.js สร้าง `quickReply.items` (action type=message). **เฟส 4 FB parity:** `setFbStage/setFbOwner` + `changeStage/changeOwner/toggleAiOff` เลิก `if(isFb)return` (branch แทน) · `searchFbMessages` + search effect channel-aware ([q,channel]) · owner badge เปิดให้ FB (`!isSup`) · reply button เปิด FB (`m.fb_message_id`) → fb-send.js `reply_to.mid` (fallback ส่งไม่อ้างถ้านอกกรอบ 24ชม.) · auto-assign คนตอบแรกครอบ FB ด้วย · realtime FB มีอยู่แล้ว (mig 044). **ยังไม่ได้:** FB reply-quote แสดง preview ในแอป (ส่งได้ ลูกค้าเห็น quote), gin index fb_messages(text). **ทำไม่ได้ (LINE OA):** typing, read receipt, unsend, ส่งไฟล์เนทีฟ.

**คอมเมนต์ Facebook (v566, 2026-08-02, mig `193_fb_comments.sql`).** เจ้าของขอทำคอมเมนต์ใต้โพสต์ + ถามเรื่องสิทธิ์ Meta → เตรียมโค้ดรอสิทธิ์ผ่าน.
- **⚠️ สิทธิ์ Meta ที่ต้องขอ (คู่กับโค้ด):** ชื่อลูกค้าแชตขึ้น "ผู้ใช้ Facebook" เพราะ `pages_messaging` ยัง**ไม่ผ่าน advanced access** (Messenger User Profile API คืน null ตอน dev — โค้ดดึงชื่ออยู่แล้ว [fb-webhook fetchProfile]) · **คอมเมนต์ต้อง `pages_read_engagement`(อ่าน)+`pages_manage_engagement`(ตอบ/ซ่อน)** ซึ่ง**ยังไม่มีในลิสต์** ต้องเพิ่ม+ส่งรีวิวรอบใหม่. ก่อนสิทธิ์ผ่าน = ยังไม่มีคอมเมนต์เข้า (webhook feed ไม่ส่ง/from เป็น null).
- **DB (mig 193):** `fb_comments` (comment_id unique/post_id/parent_id/from_id/from_name/message/permalink/is_hidden/replied/status open|done|hidden/assigned_to/commented_at · RLS read=authenticated, write=office admin/sales/exec/finance/hr เหมือน fb_contacts).
- **fb-subscribe.js:** เพิ่ม `feed` ใน subscribed_fields (เดิม messages,messaging_postbacks,message_echoes).
- **fb-webhook.js:** วน `entry.changes` field='feed' item='comment' → upsert fb_comments (Prefer merge-duplicates) + notify office · ข้ามคอมเมนต์ของเพจเอง (from.id===pageId()) · verb remove/hide → อัปสถานะ.
- **fb-comment.js (ใหม่, office JWT):** action reply(`POST {comment_id}/comments`)/hide|unhide(`POST {comment_id}?is_hidden=`)/private(`{PAGE}/messages recipient:{comment_id}`)/done(อัป status เฉย ๆ).
- **api.js:** listFbComments(status)/countOpenFbComments/fbCommentAction(action,comment_id,text).
- **UI:** `FbComments.jsx` (แยกไฟล์ · แท็บ open/done/hidden/all + การ์ดคอมเมนต์ + ตอบ/ตอบเป็น DM/ซ่อน/ปิดงาน) · Chat.jsx เพิ่ม channel `"cm"` (isCm) เป็น **overlay** เต็ม chat-wrap (zIndex 6) มีปุ่ม "← แชต" กลับ · guard effects (loadContacts/realtime/search) ให้ `if(isCm)return` — ไม่ยุ่งระบบ contact เดิม.
