วางไฟล์โลโก้ที่นี่
==================

1. เซฟรูปโลโก้ AMC AIR ที่ส่งในแชต เป็นไฟล์ชื่อ:  logo.png
   ไว้ในโฟลเดอร์นี้  (app/public/logo.png)

2. แนะนำ: รูปสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใส (PNG) ขนาด ~512x512
   จะคมทั้งบนเว็บ, favicon (ไอคอนแท็บ) และบนใบพิมพ์

3. เซฟเสร็จแล้วบอกผม — ผมจะ commit + push ขึ้นเว็บให้

(ลบไฟล์ README นี้ทิ้งได้ ไม่จำเป็นต้องเก็บไว้)
